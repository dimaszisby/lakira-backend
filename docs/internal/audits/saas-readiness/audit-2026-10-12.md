and C3 are closed.**

## 3. Methodology

1. **Kit first.** The method (D-01) and the verdict rule (D-02) were written before a gate was run
   or an agent started.
2. **Clean install, then the gates**, each with its exit code.
3. **Three agents**, started after the install, reading the tree and running no code. The
   architecture agent linted synthetic source on standard input, which writes nothing.
4. **Reproduction of every caveat ground** by the main thread against built or running code.
5. **Fork dry-run** on two fresh clones (§5).
6. **Appendix B scans** (§6).

Each reproduction ran on a throwaway process: the built server on a spare port, a local listener
standing in for Sentry, a scratch copy of the spec validator, and scratch copies of the bootstrap
script's inputs.

## 9. Risk-ranked recommendations

1. **W1 / C5** (≤1h): add `net.peer.ip`, `net.host.ip` and the other socket-address attributes to
   the scrubber's drop list, with a test that sends a real transaction through the SDK and reads
   what leaves, as this run did. **Then a dated run**, which can restate GOLD if C5 closes.
2. **W2** (≤1h): require a minimum length for `JWT_SECRET`, at least in production, and decide
   whether startup refuses the template's placeholder.
3. **W3 and T3** (≤½ day together): both are the bootstrap script acting on a name it did not
   expect. Match `.env.test`'s user to `.env`'s, stop printing "copied" when nothing was, and make
   the rename patterns safe for a name that starts with the template's.
4. **W4** (≤1h): apply the `guest` refusal to the URL the connection uses, and correct ADR-0036.
5. **R11** (≤½ day): move `PersistenceTransaction` to the domain layer, or record that the
   application's ports are part of what the domain may import.
6. **W5, W6, W7**: as tracked.

One caveat blocks a clean GOLD where four did. ADR-012 did what it was written for: three caveats
closed on their named routes while the graders still searched each caveat's whole purpose and
reported what they found as findings. C5 stayed open because its grader placed the peer address
under V3, as part of what a transaction carries, and not outside it. That line is the grader's to
draw, and the main thread did not move it.
